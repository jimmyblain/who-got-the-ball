# Who's Got The Ball?

A guided conversation for two people on one phone. Pick one shared responsibility that's been on your mind, take turns answering who you think is holding it and why, then see both answers side by side and talk it through.

The app is being rebuilt as a one-phone MVP. The earlier two-account version lives on the `archive/v1-two-account` branch.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
